# 开包有喜 RipJoy — 宝可梦 TCG 开包模拟器 · 产品文档 PRD

> 版本 v1.1 ｜ 2026-10-29 回写（v1.0 为 2026-10-27）
> 一句话：**用真实卡池、真实稀有度、社区校准概率，做出手机上最有「撕包仪式感」的宝可梦开包模拟器。**
> 非官方粉丝作品：不售卖、不赌博、无真实货币抽卡；卡图与数据来自 TCGdex 开放数据库，版权归 Nintendo / Creatures Inc. / GAME FREAK inc. 与各位画师所有。

---

## 1. 背景与机会

- 集换社等平台证明了国内 TCG 人群对「卡价、稀有度、出率」的高度敏感；用户本人即重度 TCG 关注者（大阪オリパ期望值测算、PSA10 单卡收藏）。
- 现有开包模拟器的问题：PokéRip 等网页版功能全但演出弱（无分稀有度特效、无粒子、无收藏闭环）；App 版 PokeTCG Pulls 有收藏册但视觉粗糙；全栈版 PokemonTcgSimulator 功能堆砌（分级/PvP/拍卖）但开包本身不够爽。
- **差异化定位：不做大而全，只把「开一包」这 30 秒做到极致** —— 撕包 → 蓄势 → 逐张揭晓 → 高稀有全屏演出 → 入册。演出强度严格跟稀有度挂钩，像真实开包直播一样有预期管理。

## 2. 目标用户与场景

| 用户 | 场景 | 核心诉求 |
|---|---|---|
| TCG 玩家/收藏者 | 买不起/舍不得拆实卡时解馋；新弹发售前试手气 | 卡池真实、概率可信、出 SAR 要有排面 |
| 开包主播/内容人群 | 直播、录屏素材 | 演出可截图/录屏、连开、统计 |
| 泛宝可梦粉丝 | 碎片时间、通勤 | 手机单手操作、打开即玩、无注册 |

## 3. 产品原则

1. **真实优先**：卡池 = 真实弹系全卡（TCGdex）；每张卡带真实稀有度与参考价（Cardmarket 趋势价）；概率模型公开透明、可查、可配置，绝不暗改。
2. **演出分级**：特效预算按稀有度分配 —— 平卡快过、高稀有慢放。稀有度越高，前摇（anticipation）越长。
3. **手机优先**：竖屏单手、拇指热区、震动反馈、安全区适配；桌面端为放大版同一体验，不做两套。
4. **零门槛**：无注册、无后端、打开即开；收藏与统计存 localStorage。
5. **克制 monetization 叙事**：本作不做付费抽卡；用「无限开」反衬实体卡的稀缺，附理性提示。

## 5. 概率模型（核心）

### 5.1 稀有度体系与归一

TCGdex 原始稀有度 → 游戏内等级（决定演出与配色）：

| 等级 | 原始稀有度 | 主色 | 演出级别 |
|---|---|---|---|
| C | Common | 灰 | L0 |
| U | Uncommon | 绿 | L0 |
| R | Rare（闪） | 蓝 | L1 全息扫光 |
| RR | Double Rare（ex） | 紫 | L2 粒子+轻震 |
| ACE | ACE SPEC Rare | 粉紫 | L2 |
| UR | Ultra Rare（全图） | 金紫 | L3 光柱+慢放 |
| AR | Illustration Rare | 彩虹 | L3 彩虹粒子雨 |
| SAR | Special Illustration Rare | 彩虹金 | **L4 全屏演出** |
| HR | Hyper Rare（金卡） | 纯金 | **L4 金粉爆发** |

### 5.2 卡槽模型（EN 10 张包，朱诺/朱紫时代标准包）

- 槽 1–4：Common
- 槽 5–7：Uncommon
- 槽 8–9：反闪槽 —— 83% 反闪 C/U/R、12% AR、4% UR、1% SAR/HR 池（两槽独立 roll）
- 槽 10：稀有槽 —— 62.4% R、21% RR、7% ACE/UR、7.5% AR、1.6% SAR、0.5% HR

> 口径说明（必须在产品内「概率公示」页展示）：官方从未公布完整出率；本模型以 TCGplayer 大样本开箱统计与 PokéRip 等社区校准值为参照做「可玩性校准」——SAR 单包综合概率约 3–4%（高于真实零售约 1% 量级），目的是让模拟在合理包数内可体验高稀有演出。v2 将提供「真实模式」开关：SAR 回落至 ~1.2%、HR ~0.7%，并标注样本来源。
>
> **v1.1 变更（2026-10-29）**：「真实模式」方案被更优解取代——简中五弹官方公布了每包构成与生产配比，已直接按**官方口径**实现（卡槽规格驱动 `spec`：平卡槽 + 闪卡槽、组内按种类数抽取、球纹/大师球为同卡闪卡工艺），10 万包模拟与官方条件分布偏差 ≤0.1pct，官方表存档于 `docs/official-tables/`；EN/JA/TW 维持社区校准并在公示页双轨标注。原「真实模式」开关不再开发。
> 日版 7 张包（sv2a）：3C + 2U + 1 反闪槽 + 1 稀有槽，权重同构。

### 5.3 保底与体验设计

- **首包保底**：新用户第一包稀有槽必出 AR 以上（一次性，localStorage 标记）——让每位验收者/新用户 30 秒内看到 L3+ 演出。
- **十连**：一键连开 10 包，逐包快进，最后出「十连总结算」（最佳卡置顶、总价值、稀有度分布）。
- 无暗保底、无伪随机种子操纵：每次 roll 独立，历史页可查每包结果，概率页可查模型。

## 6. 核心流程与演出脚本

```
选弹页 → 卡包页（整盒/单包视觉） → → 蓄势叠卡 → 逐张揭晓 → 结算 → 入收藏册
```

### 6.1 撕包
- 卡包为 CSS 绘制的真实比例包装（弹系 Logo + 主色 + 锯齿封口）。
- 交互：**按住上滑/点按撕口**触发；封口沿锯齿裂开（clip-path 动画）+ 撕拉音效（WebAudio 合成，无素材依赖）+ 轻震动；卡片从包口滑出成扇形叠卡。

### 6.2 逐张揭晓（核心爽点）
- 卡背朝上叠放，点击/上滑翻下一张；**翻卡前**卡缘会「漏光」：L2 紫晕、L3 彩虹晕、L4 金色呼吸光 —— 制造「下一张有货」的预期。
- 翻卡为 3D flip（rotateY + 透视），带全息扫光层（holofoil 渐变随翻转角度移动）。
- L0/L1 快节奏（可长按加速/一键全开）；L3+ 自动慢放并锁定输入 600ms。

### 6.3 分稀有度演出（特效矩阵）

| 级别 | 视觉 | 粒子 | 动效/反馈 |
|---|---|---|---|
| L1 R | 卡面全息彩膜扫光 | 无 | 翻转 + 光泽音 |
| L2 RR/ACE | 紫色描边辉光 | 24 颗星尘上浮 | 小幅弹跳 + vibrate 20ms |
| L3 UR/AR | 全图卡放大居中、彩虹渐变边框流光 | 80 颗彩虹粒子雨 + 光环扩散 | 背景径向光晕、vibrate [30,40,30] |
| L4 SAR/HR | **全屏接管**：背景压暗、卡面从中心放大、金/彩虹双环冲击波 | 160 颗金粉+五彩纸屑双爆发、持续漂浮微粒 2s | 屏幕微震、慢动作翻卡（900ms）、专属合成音阶、vibrate [60,60,120]、「SAR！」稀有度横幅 |

粒子系统：自研 Canvas 粒子引擎（零依赖、按级别配置 count/颜色/重力/拖尾），与 DOM 演出解耦，低端机自动降级（deviceMemory/帧率检测 → 粒子减半）。

### 6.4 卡面查看
- 点击任意已开卡 → 大图查看：**手指/鼠标拖动 3D 倾斜**，全息膜（mix-blend + 角度渐变）、SAR/HR 追加彩虹/金箔纹理层；展示编号、画师、稀有度、参考价。

### 6.5 结算页
- 本包网格总览（最佳卡高亮 + 稀有度角标）、总参考价、新卡标记（NEW）、重复数；按钮：再来一包 / 十连开 / 去收藏册。

## 8. 视觉设计

- 基调：深空藏青底（#0b1020）+ 卡包主色随弹切换；克制、精致，不用廉价渐变堆砌（遵循用户视觉偏好：克制简洁，但演出时刻允许华丽）。
- 字体：系统字体栈 + 数字等宽；标题用 700 无衬线。
- 卡片比例 63:88 真实比例；圆角、阴影、 foil 质感统一由 `.card` 组件承载。
- 动效曲线：翻卡 cubic-bezier(.2,.7,.2,1)；全屏演出用 easeOutQuint；全站动效 60fps、低端机降级策略明确。

## 9. 技术方案

- **形态**：零构建静态站（原生 HTML/CSS/JS ES Modules），GitHub Pages 直接托管 —— 加载快、无构建失败风险、方便二次开发时迁移 React/Vite（PRD 附迁移说明）。
- 结构：`index.html` / `src/styles.css` / `src/app.js`（状态机：select→pack→reveal→summary）/ `src/engine.js`（概率与抽卡）/ `src/particles.js`（Canvas 粒子）/ `src/fx.js`（音效合成/震动/全息）/ `data/*.json`（真实卡池）/ `scripts/fetch-set.mjs`（数据更新脚本）。
- 状态：单页四视图切换；收藏/统计 localStorage（key 版本化 `ripjoy.save.v1`）。
- 性能：EN/JA/TW 卡图走 TCGdex CDN（列表 low / 大图 high）；简中五弹数据为内嵌卡图的静态 JSON（本地全量约 83MB），线上按弹分片（每片 ≤3.6MB）懒加载、首开一弹约 15–21MB 后缓存；粒子 Canvas 独立 rAF、页面隐藏自动暂停。
- 合规：页脚粉丝作品声明；不使用官方 Logo 素材做商业暗示；概率公示常驻入口。

## 10. 验收标准（2026-10-28）

1. 手机打开链接 3 秒内可开第一包；第一包必见 AR+ 演出。
2. 4 个弹系均可开，卡图、稀有度、价格与真实卡对照无误（抽查每弹 SAR 各 1 张）。
3. SAR/HR 触发 L4 全屏演出（粒子+横幅+震动），普通卡不误触发。
4. 十连、收藏册、统计数据在刷新后仍在（localStorage 持久化抽查）。
5. GitHub 仓库公开可访问，README 含在线地址、概率口径、数据来源；GitHub Pages 已上线。

## 11. 风险

- TCGdex CDN 偶发慢：列表图先 low 后 high 渐进；关键演出卡预加载下一张。
- 概率口径争议：公示页写清「社区校准、非官方」并给出参照来源，避免被当作官方出率引用。
- 版权：粉丝非商业定位、声明齐全；EN/JA/TW 卡图走 CDN 引用，简中卡图因无可用 CDN 以 data URI 内嵌于数据文件（来源：神奇宝贝百科扫描与公开图库），权利归版权方所有，如权利方提出要求将第一时间下架处理。
